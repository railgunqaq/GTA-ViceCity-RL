# 发布证据与删减范围

本仓库是 2026-11-13 从现有工作区整理出的源码快照，不包含原始 Git 历史。目录结构保留 `ml/`、`reVC-src/` 和少量 `audit/`，以维持源码导入及现有诊断命令的相对路径。

## 收录

- 18 个现行 Python 入口/模块及 7 个离线测试文件。
- 原生源码、构建脚本、librw 源码与原有许可证、Miles 兼容头；包含原生代码实际引用的着色器 `.inc` 和 Windows 图标。
- 墙体修复报告、建筑入口分析、经过原生查询的路线提示、单点成功摘要与轨迹图。
- smoke 训练链路验证摘要、2026-11-13 轨迹审计结果及下一阶段评估。
- 本次发布检查与离线回归结果摘要。

## 未收录

- 完整游戏、原始碰撞资源及完整碰撞网格导出、声音、地图、纹理、游戏文本和 SCM。
- 已编译游戏、PDB、SDK/运行库二进制、预编译 Premake、生成的 Visual Studio 工程和构建目录。
- 旧模型、训练运行目录、大型 JSONL 轨迹、截图堆积、重复游戏备份与压缩包。
- 本机 IDE/助手配置、读取 API 配置的实验脚本、历史临时调试脚本、旧上游 CI 工作流。

原始记录仍保留在本地原工作区。报告里出现的历史日志/备份名称是来源说明，不表示这些文件包含在发布仓库中。尤其 `navigation-placement-v5/trace.jsonl` 没有发布，因此 `trajectory-audit.json` 中的复算结论和源 SHA256 可供核对，但不能只凭这个精简副本完整重做轨迹复算。

JSON 摘要中的个人工作区绝对路径已改为仓库相对路径。任务步数、奖励、原生状态、源文件哈希及实测结果未改写。原有 `C:/VC` 游戏路径作为记录/默认配置保留，不包含个人目录。

`building-collision-summary.json` 仅保留来源哈希、模型标识、范围和数量；完整顶点、三角形及碰撞盒不随包。需要重新分析时，可用 `extract_building_collision.py` 读取自己的本地游戏数据，输出文件也应按本地数据管理。

`PUBLISH_MANIFEST.json` 为发布文件的工作副本 SHA256 清单，不包含它自身；Git 可能按 `.gitattributes` 规范化文本换行，因此其文件哈希不等于 Git blob 对象 ID。此清单不声称恢复了上游 reVC/librw 的原始提交身份。
